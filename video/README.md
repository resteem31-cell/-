# 아나도 5단계 피부 설계 영상 (15초)

- `anado-skin-5step-15s.mp4` — 완성 영상 (1080x1920 세로, 30fps, 15초, 무음)
- `skin-5step.html` — 영상 원본. 브라우저로 열면 반복 재생, `?t=7.5` 를 붙이면 그 시점에서 멈춤
- `render.js` — 원본을 MP4로 다시 뽑는 스크립트

## 구성
| 시간 | 장면 |
|---|---|
| 0–2.6초 | "겉만 관리하는 화장품이 아닙니다" · 골드 앰플 방울이 피부에 떨어져 스며듦 |
| 2.6–4.6초 | STEP 01 노화세포 사멸 (세놀리틱) — 회색 노화세포가 분해 |
| 4.6–6.5초 | STEP 02 세포 에너지 활성화 — 세포가 빛나며 에너지 파동 |
| 6.5–8.5초 | STEP 03 표피·진피 성장인자 (EGF·FGF·IGF) — 신호 파동, 표피 두꺼워짐, 섬유아세포 증가 |
| 8.5–10.4초 | STEP 04 콜라겐 재생 유도 — 끊기고 늘어진 섬유가 촘촘·팽팽하게 |
| 10.4–12.4초 | STEP 05 세포 구성 단백질 (펩타이드) — 펩타이드 사슬이 결합해 구조망 형성, 주름 펴지고 피부 리프팅 |
| 12.4–15초 | 5단계 전체 흐름 정리 → 피부 표면에서 빛이 퍼지며 화이트아웃 → ANADO 로고 엔딩 |

## 문구 고치기
`skin-5step.html` 위쪽 `COPY` 안의 글자만 바꾸고 다시 렌더링합니다.

```bash
NODE_PATH=$(npm root -g) node video/render.js          # MP4 생성
NODE_PATH=$(npm root -g) node video/render.js --stills 3,9,14   # 특정 시점 PNG만 확인
```
(Playwright, ffmpeg 필요. 폰트는 Google Fonts에서 불러오므로 인터넷 연결 필요)

# MONO LAB 바이탈 리부트 앰플 미스트 · 성분 영상 (30초)

- `monolab-mist-30s.mp4` — 완성 영상 (1080x1920 세로, 30fps, 30초, 무음)
- `mist-30s.html` — 영상 원본 (문구는 위쪽 `COPY` 에서 수정)
- `assets/monolab-mist.jpg` — 제품 사진

| 시간 | 장면 |
|---|---|
| 0–3.2초 | 제품 등장 · 미스트 분사 · "바이탈 리부트 앰플 미스트" |
| 3.2–6.2초 | 미스트가 피부에 닿고, 늘어진 피부 표면이 즉시 올라감 — "뿌리는 순간 즉각 리프팅" |
| 6.2–8.2초 | "겉은 즉각, 속은 진피까지" — 즉각(표면 막) / 지속(진피 성분 공급) |
| 8.2–9.8초 | "왜 3가지를 함께 써야 할까요?" |
| 9.8–13.2초 | STEP 1 SIGNAL · 3종 성장인자(EGF·aFGF·IGF-1) — 진피 섬유아세포에 신호 전달 |
| 13.2–16.6초 | STEP 2 ACTIVATE · 4종 멀티 펩타이드 — 섬유아세포 활성, 새 섬유 생성 |
| 16.6–20초 | STEP 3 BUILD · 15종 아미노산(프롤린·글리신·알지닌·타우린) — 콜라겐 재료 공급, 진피가 촘촘해짐 |
| 20–23초 | "세 가지가 함께일 때 진피부터 차오르는 탄력" (신호=공사 지시, 활성=일꾼, 재료=벽돌) |
| 23–27.6초 | 추천 대상 4가지: 늘어진 피부 / 탄력 필요 / 리프팅 시술 동시 사용 / 시술 후 유지 관리 |
| 27.6–30초 | 제품 엔딩 · "뿌리는 순간, 즉각 리프팅" |

```bash
NODE_PATH=$(npm root -g) node video/render.js --page mist-30s.html
```
렌더링할 때 Noto Sans KR 폰트를 처음 한 번 내려받아 `video/.fontcache/` 에 저장합니다 (git 에는 올리지 않음).
