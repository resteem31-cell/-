# 아나도 5단계 피부 설계 영상 (15초)

- `anado-skin-5step-15s.mp4` — 완성 영상 (1080x1920 세로, 30fps, 15초, 무음)
- `skin-5step.html` — 영상 원본. 브라우저로 열면 반복 재생, `?t=7.5` 를 붙이면 그 시점에서 멈춤
- `render.js` — 원본을 MP4로 다시 뽑는 스크립트

## 구성
| 시간 | 장면 |
|---|---|
| 0–2.6초 | "겉만 관리하는 화장품이 아닙니다" · 골드 앰플 방울이 피부에 떨어져 스며듦 |
| 2.6–4.6초 | STEP 01 노화세포 사멸 (세놀리틱) — 회색 노화세포가 분해 |
| 4.6–6.5초 | STEP 02 세포 에너지 활성화 — 세포가 빛나며 에너지 파동 |
| 6.5–8.5초 | STEP 03 표피·진피 성장인자 (EGF·FGF·IGF) — 신호 파동, 표피 두꺼워짐, 섬유아세포 증가 |
| 8.5–10.4초 | STEP 04 콜라겐 재생 유도 — 끊기고 늘어진 섬유가 촘촘·팽팽하게 |
| 10.4–12.4초 | STEP 05 세포 구성 단백질 (펩타이드) — 펩타이드 사슬이 결합해 구조망 형성, 주름 펴지고 피부 리프팅 |
| 12.4–15초 | 5단계 전체 흐름 정리 → 피부 표면에서 빛이 퍼지며 화이트아웃 → ANADO 로고 엔딩 |

## 문구 고치기
`skin-5step.html` 위쪽 `COPY` 안의 글자만 바꾸고 다시 렌더링합니다.

```bash
NODE_PATH=$(npm root -g) node video/render.js          # MP4 생성
NODE_PATH=$(npm root -g) node video/render.js --stills 3,9,14   # 특정 시점 PNG만 확인
```
(Playwright, ffmpeg 필요. 폰트는 Google Fonts에서 불러오므로 인터넷 연결 필요)
