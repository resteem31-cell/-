# ANADO 아나도 홈페이지

40~60대 여성 고객을 위한 아나도 제품 소개 + 피부타입 테스트 + 상담 신청(DB 수집) 홈페이지입니다.
별도 빌드 없이 바로 열리는 정적 사이트입니다 (`index.html`).

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 홈페이지 본문 (브랜드, 4단계 루틴, 제품 4종, 피부타입 테스트, 상담 신청서) |
| `css/style.css` | 디자인 (아이보리 · 골드 톤, 큰 글씨) |
| `js/main.js` | 피부타입 테스트, 신청서 검사·전송 |
| `js/config.js` | **신청서 저장 주소 설정** |
| `apps-script/Code.gs` | 신청 내용을 구글 스프레드시트에 쌓는 스크립트 |
| `assets/img/` | 제품 사진, 로고 |

## 상담 신청 메일·시트 연결 (처음부터 설정)
1. 구글 스프레드시트를 새로 만들고 [확장 프로그램] → [Apps Script] 를 엽니다.
   (script.google.com 에서 따로 만든 프로젝트도 동작하지만, 시트에서 여는 방법을 권장합니다)
2. 편집기의 기존 코드를 **모두 지우고** `apps-script/Code.gs` 전체를 붙여넣은 뒤 저장(💾)합니다.
3. 위쪽 함수 선택 칸에서 `testSetup` 을 고르고 [실행] 을 누릅니다.
   - "권한 검토" → 구글 계정 선택 → "고급" → "(안전하지 않음)으로 이동" → [허용]
   - 아래 실행 로그에 `✅ 설치 완료!` 가 나오고, resteem@naver.com 으로 테스트 메일이 오면 성공입니다 (스팸함 확인).
4. [배포] → [새 배포] → 톱니바퀴에서 **웹 앱** 선택
   - 실행 사용자: **나** / 액세스 권한이 있는 사용자: **모든 사용자** → [배포]
5. 나온 웹 앱 URL(…/exec)을 `js/config.js` 의 `SUBMIT_URL` 에 넣습니다.
6. 웹 앱 URL 을 브라우저에서 열어 `{"ok":true,...}` 가 보이는지 확인합니다.

### 메일이 오지 않을 때
- Apps Script 왼쪽 메뉴 [실행 기록] 에서 `doPost` 실행이 있는지 봅니다.
  - **없음** → 신청이 스크립트까지 오지 않음: 액세스 권한이 "모든 사용자"인지, `SUBMIT_URL` 이 최신 배포 주소인지 확인
  - **실패** → 눌러서 오류 내용을 확인 (대부분 권한 미허용 → 3번 `testSetup` 다시 실행)
- 코드를 고친 뒤에는 [배포] → [배포 관리] → 연필 → 버전 "새 버전" → [배포] 를 해야 반영됩니다. 이 방법은 주소가 바뀌지 않습니다.
- 시트의 마지막 칸 "메일 발송" 에 실패 이유가 기록됩니다.

## 공개 전 확인할 것
- `index.html` 하단 푸터의 `[상호명]`, `[대표자명]`, `[사업자등록번호]`, `[주소]`, `[고객센터]` 를 실제 정보로 바꿔 주세요.
- 개인정보 수집·이용 동의 문구(보유 기간 등)가 실제 운영 방침과 맞는지 확인해 주세요.
- 제품 설명 문구는 상세페이지를 바탕으로 작성했습니다. 화장품 표시·광고 기준에 맞는지 최종 확인해 주세요.

## 사이트 공개 방법

Netlify 등에 폴더를 그대로 올려도 됩니다.
